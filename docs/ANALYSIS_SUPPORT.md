# M08F — 분석 지원과 안전 경계

현재 계약: `asset-analysis.v2` / 입력 `bounded-multiformat.v1` / 출력 `asset-description.v4`. 유형은 파일 확장자로 자동 지정하지 않는다. 실제 지원은 아래 형식·파서·검증된 모델 입력에 의해 결정되며 A01~A14 지원 행렬은 `analysis_contract.py`에 포함된다. 모든 형식의 렌더·엔진 호환을 보증하지 않는다.

| 입력 | 비AI 기술 수집 | 명시적 수동 AI 경로 | 제한·미지원 |
|---|---|---|---|
| PNG/JPEG | 원본 치수·채널·알파/투명 픽셀·프레임 | image 모델, 최대512px 파생 JPEG | 치수·투명도는 AI 추정으로 받지 않음 |
| GIF/APNG | 실제 프레임/시간/loop·일정 시간일 때 FPS | image 모델, 앞8프레임 시간순 콘택트 시트 | 최대64프레임·전체32M 디코드 픽셀, 3D 포즈 렌더 없음 |

분류·역할·스타일·태그·색상·소재·동작/루프 추천·오디오 전사는 **미확정 AI 제안**이다. 코드/모델이 실제 관측하지 않은 정점 수·단위·리그·권리·호환 성공을 생성하지 않는다. 와이어프레임에서는 표면 소재/색상/동작 제안을 거부한다. 기술 관측은 `source=parser`, 의미 제안은 `suggestionStatus=proposed`로 구분한다. 알려진 미지원 형식과 형식 미확인을 구별하며 미확인을 지원으로 승격하지 않는다.

## 입력·검토·전송 계약

등록된 활성 원본의 단일 파일을 안전한 읽기 경로로 참조한다. 원본20MB, 정적 이미지16M 픽셀, 3D 정점10만/면10만/누적 디코드100만 스칼라 한도다. 와이어프레임은 앞1만 면의512px 직교 투영이다. 다중 파일의 자동 합성 AI 분석은 미지원이며 실제 등록된 구성 요소는 파일/내용 SHA-256/locator로 안정 ID를 만든다. 종속 URI는 표시만 하며 파일/네트워크를 열지 않는다.

사전 검토는 추론·임베딩·Job을 생성하지 않는다. 실제 모델 profileVersion, 출력 JSON 스키마/프롬프트 SHA-256, 저장된 불변 유형/축 사전 버전·내용 지문을 snapshot과 planToken에 포함한다. 검토 입력 지문은 대상 ID/크기/mtime_ns/가용성 목록의 SHA-256이다. 원본 바이트를 읽은 지문이 아니며 동일 크기/mtime을 유지한 내용 변경 탐지 보장은 없다. 승인된 실행에서 읽은 원본 바이트 SHA-256을 별도로 저장한다. 계약·사전·입력/모델/가격이 바뀌면 재검토하며 대기 중 계약 변경도 추론 전에 차단한다.

이미지/3D/애니메이션은 파생 JPEG와 고정 프롬프트만 공급자로 보낸다. 기본 공개 사전의 코드/영문 이름은 이미지 프롬프트에 포함되지만 사용자 분류/제작/권리 메타데이터는 보내지 않는다. 오디오는 PCM WAV 원본 전체, 텍스트는 UTF-8 원문 전체를 보내므로 UI에 각각 전송 범위를 명시한다. 외부 전송/유료는 기본 비활성 및 작업별 승인·보수적인 비용 상한/예산 예약을 유지한다. 오디오 입력은 contextLength 전체에 max(prompt,audio) 단가를 적용한다. 지원하지 않는 비영점 추가 과금 항목은 검토를 거부한다. 실제 키가 텍스트 입력에 있으면 전송을 차단한다. 모델 출력 길이 종료·스키마 위반·부당 측정값은 성공하지 않는다.

## 사용자 확정·이력·벡터

새 결과는 실제 결과 ID를 참조하는 불변 AI claim과 features에 남고 사용자 값을 덮어쓰지 않는다. 분류 제안은 현재 값과 변경 후 값을 검토한 뒤 실제 결과 ID/검토 토큰/revision/명시 승인으로만 적용한다. 비어 있는 제안은 기존 값을 보존하고 대표 분류·역할·스타일만 변경한다. 나머지 색상/소재/동작/전사는 미확정 상태로 남는다. 다른 변경이 있으면 METADATA_CONFLICT로 다시 검토해야 한다. 실패/취소/재분석은 이전 성공과 사용자 결정을 보존하고 혼합 결과에 부분 성공을 표시한다.

명시 기술 수집은 모델 없이 불변 parser claim을 저장하고 실제 치수/길이를 기존 수치 검색에 반영한다. 저장 관측 이후 원본 크기/mtime 변경·누락은 stale로 표시한다. MP4 선언 시간은 디코드된 실측 시간으로 수치 검색에 넣지 않는다.

임베딩 입력은 AI 설명/태그와 공개 `catalog_search_projection`이다. 연락처·원본 경로·출처 URL·구매/증빙/메모는 제외한다. 공개 메타데이터 변경 시 기존 벡터는 지문 불일치로 stale에서 보존·제외되며 자동 생성/삭제하지 않는다. 새 명시 생성/재구축만 모델을 호출한다. 구 입력 정책의 벡터도 새 지문과 다르면 재확인 상태가 된다.

## 검증 구분

Core/컴포넌트 자동화와 동봉/설치 Core에서 실제 합성 파일 파서를 검증한다. 설치 통신 검증은 **실제 AI가 아닌 명시적인 모의 로컬 공급자**를 사용하며 보고서의 `realModelInference=false`로 구분한다. 현 PC에 로컬 모델 런타임/가중치가 없으므로 새 버전의 실제 모델 품질·외부 오디오/유료 공급자 호출은 미검증이다. 자동 설치/모델 다운로드/외부 호출·GUI 조작은 하지 않는다. 이전 PNG 실제 모델 검증 이력은 과거 버전의 기록으로 보존한다.
