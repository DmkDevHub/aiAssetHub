## D-025 — M05 초기 모델 검사
초기 로컬 어댑터는 Ollama, 외부 카탈로그는 OpenRouter로 한정한다. 공급자 메타데이터의 직접 REST 조회에는 표준 라이브러리를 사용해 새 의존성을 추가하지 않는다. 생성/추론 SDK와 실제 분석 실행은 M06 범위다. 사용자 제공 ID를 보존하며 설치·다운로드·추론·유료 폴백을 암묵적으로 수행하지 않는다.

## D-026 — M06 수동 분석 실행
명시적 Job 생성 후 Python Core의 단일 승인 작업 스레드가 별도 SQLite 연결(WAL·쓰기 트랜잭션)로 처리한다. 비공개 파이프의 3초 응답 제한을 유지하며 느린 모델 호출은 별도 작업에서만 수행한다. Ollama/OpenRouter 공식 네이티브 REST 규격을 표준 HTTP 클라이언트로 직접 호출해 새 SDK 의존성 없이 구현한다. 외부/유료는 작업별 재승인·사전 상한 예약을 요구한다. 메타데이터 버전/가격 변경·원본 stat 변경 시 자동 재시도/폴백 없이 실패한다. 원본은 읽기만 하고 파생 512px JPEG를 사용한다. 실제 기본 로컬 검증은 CPU qwen3-vl:2b, Ollama 설치·다운로드는 2026-10-28 사용자 명시 승인이다.

## D-027 — M07 로컬 임베딩과 버전 재구축
Ollama의 로컬 embedding capability 모델만 명시적으로 설정한다. SQLite 기존 asset_embeddings에 정규화 float32 벡터를 저장하고 모델·차원·메타데이터·텍스트 규격별 공간을 분리한다. 새 의존성/벡터 DB 없이 코사인 및 역순위 합산으로 검색한다. 생성·질의·전체 재구축은 각각 명시 실행하며 재구축은 전체 계산 성공 후 현재 공간/FTS를 원자적으로 교체한다. 기존 공간은 보존하고 자동 정리·자동 임베딩·모델 다운로드·외부/유료 폴백은 제공하지 않는다. 실제 다국어 모델 및 한국어 품질의 최종 검증은 추가 다운로드 승인 대기이며 내부 fixture 결과와 구분한다.
