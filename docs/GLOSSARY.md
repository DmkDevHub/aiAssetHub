# GLOSSARY — 기술 약어와 뜻

| 용어 | 영문 풀네임 | 한국어 의미 |
|---|---|---|
| AI | Artificial Intelligence | 인공지능 |
| API | Application Programming Interface | 응용 프로그램 인터페이스 |
| MCP | Model Context Protocol | 모델 컨텍스트 프로토콜 |
| SDK | Software Development Kit | 소프트웨어 개발 키트 |
| UI | User Interface | 사용자 인터페이스 |
| UX | User Experience | 사용자 경험 |
| DB | Database | 데이터베이스 |
| SQL | Structured Query Language | 구조화 질의 언어 |
| FTS | Full-Text Search | 전문 검색 |
| FTS5 | Full-Text Search 5 | SQLite 전문 검색 확장 기능 |
| IPC | Inter-Process Communication | 프로세스 간 통신 |
| WAL | Write-Ahead Logging | 선기록 로그 방식 |
| ID | Identifier | 식별자 |
| UUID | Universally Unique Identifier | 범용 고유 식별자 |
| E2E | End-to-End | 종단 간 통합 |
| NSIS | Nullsoft Scriptable Install System | Windows 설치 패키징 시스템 |
| PRD | Product Requirements Document | 제품 요구사항 정의서 |
| Sidecar | Sidecar Process | 본 앱과 함께 구동되는 보조 실행 프로세스 |
| Embedding | Embedding | 의미 데이터를 수치 벡터로 변환하는 표현 |
| Vector | Vector | 벡터, 수치 배열 |
| Provider Adapter | Provider Adapter | AI 공급자별 통신을 공통 인터페이스로 변환하는 계층 |
| Model Registry | Model Registry | AI 모델 카탈로그·지원 기능 관리 체계 |
| Unity Editor | Unity Editor | Unity 게임 제작 편집기 |
| AssetDatabase | Asset Database | Unity 프로젝트 에셋 관리 API |
| AppData | Application Data | Windows 사용자별 앱 데이터 디렉터리 |

문서에서 약어를 처음 사용할 때 영문 풀네임과 한국어 뜻을 병기하는 것을 원칙으로 한다.
