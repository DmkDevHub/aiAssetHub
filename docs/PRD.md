# PRD — Product Requirements Document (제품 요구사항 정의)

버전: v0.5 · 상태: 설계 기준 · 최상위 목적: **에셋 분석·관리 + MCP 기반 실제 개발 자동화**

## 대상 사용자와 핵심 시나리오
- Windows에서 개인이 보유한 게임 에셋을 분류·검색·재사용하려는 개발자.
- Unity Editor와 Codex 등 AI 코딩 환경을 함께 사용하는 1인 개발자.
- 흐름 A: 폴더 선택 → 등록/스캔 → 실제 파일 갤러리/상세 확인 → 필요할 때 `AI 분석` 수동 실행 → 분석 정보 관리.
- 흐름 B: Codex에 “숲에 어울리는 나무를 골라 Unity 씬에 배치해 줘” 명령 → MCP 검색 → 원본 확인 → Unity에 실제 임포트·배치 → 성공/실패 보고.

## P0 — 반드시 제공할 사용자 기능
| ID | 기능 | 합격 기준 |
|---|---|---|
| F-001 | 폴더 등록/해제 | 선택한 로컬 폴더가 왼쪽 트리에 나타나고 앱 재실행 후 유지. 해제 시 원본 파일 삭제 금지. |
| F-002 | 파일 스캔 | 실제 파일의 경로·크기·형식 등 등록. AI 모델 호출은 **0회**. |
| F-003 | 갤러리/상세 패널 | 파일 선택 시 실제 미리보기·경로·속성이 표시됨. 지원하지 않는 형식은 안전한 대체 표시. |
| F-004 | 필터/정렬/선택 | 폴더, 타입, 분석 상태, 태그 필터와 다중 선택·목록/그리드 지원. |
| F-005 | 태그/설명 편집 | 사용자가 수정한 메타데이터가 별도로 저장되고 재스캔 후에도 보존. |
| F-006 | 수동 AI 분석 | 사용자의 클릭·대상 범위·모델 선택이 있어야만 작업 생성. |
| F-007 | 분석 범위 | 전체 / 미분석 / 완료 재분석 / 실패 재시도 / 선택 에셋 지원. |
| F-008 | 분석 큐/이력 | 대상 수·진행률·성공/실패·취소·재실행·과거 성공 결과 조회. |
| F-009 | 모델 관리 | 로컬·외부 무료·외부 유료 모델 등록/선택/연결 테스트; 유료 기본 OFF. |
| F-010 | 검색 | 파일명·태그·속성 키워드 검색과 AI 분석 결과 기반 자연어 의미 검색. |
| F-011 | MCP 검색 | AI 코딩 도구에서 `search_assets`, `get_asset` 등 호출해 실제 데이터를 반환. |
| F-012 | Unity 적용 | 편집기에서 유효한 에셋 임포트·오브젝트 배치·결과 검증. |
| F-013 | Windows 배포 | 설치형 exe에서 DB·Python 엔진·UI·기본 기능 정상 동작, 사용자 데이터 유지. |

## P1 — 확장 및 품질
- AI 모델 최신 카탈로그 갱신, 모델 호환성 검사, 분석 이력/인덱스 버전 관리.
- 파일 중복 감지, 폴더 재스캔 시 변경 및 누락 파일 표시.
- 모델별 비용 예산·사전 승인·실패 복구·품질 피드백.
- Unity 이외 도구는 **확장 인터페이스만 확보**, 실제 동작 구현은 추후 별도 요구.

## 명시적 비목표
- 클라우드 계정/서버 필수 요구, 사용자 파일의 무단 온라인 업로드.
- 폴더 등록과 동시에 AI 전체 분석.
- 에셋 원본을 자동으로 AppData에 복제하거나 삭제.
- 별도의 개발 관리/진행률 대시보드와 멀티에이전트 운영 기능.
- 모든 자산 형식의 완벽한 3D 렌더링과 모든 게임 엔진의 즉시 지원.

## 비기능 요구사항
- 오프라인 기본 기능: 폴더·파일·미리보기(지원 포맷)·로컬 DB 조회는 인터넷 없이 동작.
- 사용자 통제: AI 분석과 외부 전송, Unity 쓰기/덮어쓰기 작업은 명시적 트리거 및 권한 정책 적용.
- 데이터 신뢰성: 분석 실패나 재분석으로 기존 성공 결과가 사라지지 않는다.
- 제품 품질: 큰 폴더 작업 시 UI가 응답성을 유지하고 장시간 작업 상태가 표시된다.
- 복구 가능성: DB 백업·마이그레이션·실패 원인 기록·작업 취소 시 무결성 유지.

## 제품 완료 기준
- 사용자가 최초 실행부터 폴더 등록, 갤러리 탐색, 수동 분석, 검색, MCP 연결, Unity 씬 배치까지 한 흐름으로 시연 가능.
- `TEST_PLAN.md`의 P0 수용 테스트를 통과하고 Windows 설치본에서 동일하게 동작.
- AI Asset Hub의 목적은 **실제 개발 적용**까지이며, 에셋 검색 화면만 완성하면 최종 완료가 아님.
