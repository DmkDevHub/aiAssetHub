# AI Asset Hub v0.5 — 배포·수용 범위

## 설치와 실행
Windows x64 수동 NSIS 설치본은 `src-tauri/target/release/bundle/nsis/AI Asset Hub_0.5.0_x64-setup.exe`다. Python/SQLite/Pillow/MCP/Unity Editor 패키지를 동봉한다. Ollama·모델·Unity Editor는 자동 설치하지 않는다. 자동 업데이트는 제공하지 않으며 새 설치본으로 수동 갱신한다. 낮은 버전의 무인/업데이트 덮어쓰기는 차단한다. 서명 인증서/SmartScreen·깨끗한 PC/WebView2 신규 설치·설치 마법사 시각 배치는 별도 미검증이다.

원본 폴더를 등록한 뒤 **명시 스캔**으로 인덱스를 만든다. 스캔은 별도 Core 작업으로 실행하며 조회/health를 막지 않는다. 앱 종료로 중단되면 DB 트랜잭션을 롤백하고 다음 실행에서 자동 재스캔하지 않는다. 기존 진행 중인 같은 라이브러리 스캔을 다시 누르면 같은 작업 상태를 조회한다. 검색·등록·스캔은 분석/임베딩/유료 요청을 만들지 않는다.

## 지원 범위
- 폴더/태그/설명·분류/그룹/패키지·제작/출처/권리·복합/의미 검색·스마트 그룹/관계·명시 일괄 교환/해시 후보. 형식별 기술 파서와 분석 입력 한도는 [분석 지원 계약](ANALYSIS_SUPPORT.md)을 따른다.
- AI 분석과 임베딩은 준비된 모델에 대해 명시 실행한다. 외부/유료 기본 OFF·전송/비용/예산 검토를 적용한다. 모의 공급자 회귀는 실제 모델 품질·가격/권리 판정 증거가 아니다.
- [Unity 계약](UNITY_INTEGRATION.md)의 Windows Unity6000.6.8f1 단일 PNG→Sprite 임포트/배치·Undo·미저장 씬 정책. 다른 형식 임포트·프리팹/부모 지정·다른 Editor/OS·특정 AI 제품 Host는 검증하지 않았다.
- 진단은 실제 분석/Unity/감사 기록의 ID·상태·수치·고정 오류만 보여 준다. 공급자 보고 비용이 없으면 미확인이고 보수적 예약 상한은 청구액이 아니다.

## 백업·복구
앱의 **DB 백업·복구**에서 현재 DB를 명시 백업한다. `backups/<UUID>.sqlite`와 해시 manifest는 현재 사용자 전용 ACL로 저장한다. WAL 상태도 SQLite backup으로 일관되게 캡처한다. 백업에는 연락처·구매·원본 경로 등 개인 메타데이터가 있으므로 사용자 권한 범위 안에서 보관한다. 원본 파일/파생 캐시/OS에 저장한 API 키는 포함하지 않는다.

복구할 백업을 선택해 표시된 정확한 PowerShell 명령을 확인한 뒤 **앱을 완전히 종료하고** 실행한다. `--maintenance restore --data-dir ... --environment production --backup-id <UUID> --confirmed`는 명시 승인한 오프라인 복구다. Core의 OS lease가 남아 있으면 DATA_IN_USE로 거부한다. 현재 마이그레이션 체크섬/스키마와 일치하고 SHA256/FK/quick_check를 통과한 백업만 사용한다. 기존 DB/WAL/SHM은 `backups/pre-restore-<UUID>/`에 보존하며 교체 실패는 원상 복귀한다. 복구 후 분석/임베딩/스캔을 자동 재개하지 않는다. 구버전/미확인 DB나 증빙 파일을 임의로 고쳐서 복구하지 않는다.

기본 설치 갱신/제거는 사용자 데이터를 보존한다. NSIS 제거 화면의 별도 데이터 제거 선택은 영구 삭제이므로 백업/원본 위치를 먼저 확인해야 한다. 무인 기본 제거의 보존과 격리 업데이트는 자동 검증하고 실제 제거 화면/추가 삭제 체크박스 조작은 검증하지 않는다. 원본 등록 폴더는 앱 설치/제거 대상에 포함하지 않는다.

## 내부 수용 시나리오
모든 시나리오는 소유한 임시 파일/DB/프로젝트로 수행하며 실제 사용자 데이터·개인 Host 설정·OS 화면을 조작하지 않는다.

| 목표 | 자동화 기준 |
|---|---|
| 에셋 관리/분석 | 실제 한글 파일 수집/조회·지속 태그/설명·FTS/복합 필터·형식별 파서·명시 모의 모델 분석/성공 이력 보존·수동 임베딩의 내부 수학 fixture |
| Unity 실제 개발 | 별도 공식 SDK Host→설치 Bridge/Core→실제 batchmode Editor에서 검색/승인/PNG 임포트/GUID·Sprite/transform/Undo·부분 실패/취소·재시작 결과 보존 |
| 안정화 | 5004파일 소스 benchmark·설치본 5000파일 background scan과 동시 health·무손실 페이지·원본 SHA256·손상 형식·네트워크 차단/권한/junction·로그 마스킹 |
| 데이터 보호 | 실제 WAL 백업/해시·앱 실행 중 복구 거부·오프라인 복구·손상 백업 거부·원상 보존·이전 설치본 갱신/기본 제거 뒤 데이터 유지 |

명령·실측·실패 수정·바이너리 해시는 [검증 기록](TEST_PLAN.md)의 M10을 따른다. 내부 수용은 사용자 본인의 실데이터·모델·GUI에 대한 직접 인수 승인이나 공개 서명 배포를 대신하지 않는다. 검증되지 않은 지원을 표시하거나 사용자 데이터를 광범위하게 재분석/정리하지 않는다.
