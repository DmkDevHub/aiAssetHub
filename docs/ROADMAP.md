# ROADMAP — AI Asset Hub v0.5 세부 개발 순서

> 이 문서는 **구현 현황이 아닌 개발 계획**이다. 모든 체크박스는 최초 `미완료` 상태다. 대시보드에 개발 진행률을 표시하지 않는다.
>
> **작업 규칙:** 한 번에 하나의 `Rxx-yy`만 수행 → 내부 자동화 테스트 → 본 체크박스 갱신 → `CHANGELOG.md` 기록 → 소스·문서·테스트 함께 커밋 → 사용자 다음 지시.
>
> **검증 방식 변경 (D-019):** 아래 항목의 `화면` 문구는 사용자에게 제공할 동작·표시 목표다. 앞으로는 화면을 직접 조작하지 않고 관련 컴포넌트·상태·이벤트·라우팅·API/DB를 내부 자동화로 검증한다. 타입 검사·빌드 성공만으로 기능 성공을 판정하지 않으며, 시각적 배치·OS 화면 등 미검증 범위를 기록한다. M00의 기존 UI 확인 기록은 변경 전 이력이다.

## 공통 완료 정의(Definition of Done)
- [ ] 대상 기능의 상태·행동·입출력을 내부 자동화 테스트로 검증했으며, 실제 데이터와 격리된 테스트 fixture·mock 결과를 구분했다.
- [ ] 관련 내부 자동화 테스트를 실행하고 명령·실측 결과·미검증 범위를 기록했다. 화면 직접 조작 테스트는 수행하지 않았다.
- [ ] 폴더 등록·검색만으로 AI 분석을 실행하지 않는다는 불변식을 지켰다.
- [ ] 실패·예외·권한/비용 상태를 적절히 처리했다.
- [ ] ROADMAP, CHANGELOG 및 관련 설계 문서를 최신화하고 Git 커밋을 생성했다.

## 로드맵 보완 규칙
- 위 순서는 **제안 개발 순서**이며 파일 구조·기술 의존성 이슈가 확인되면 결정 기록 후 변경한다.
- 각 작업이 여전히 크다면 `R06-07a`, `R06-07b`처럼 더 작게 세분화하고, 내부 자동화 테스트로 독립 검증할 수 있도록 한다.
- 각 작업의 실제 기능 입력·응답·결과를 내부 자동화로 확인한다. 개발 현황 패널을 만들지 않는다.
- 구현 전에는 완료 체크박스를 선제적으로 체크하지 않는다.
