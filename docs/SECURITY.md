# SECURITY — 로컬 우선 보안·권한 정책

## 위협 모델
- 외부 모델 사용 시 개인 로컬 에셋의 원본·프리뷰가 제3자 API로 전송될 수 있음.
- MCP 또는 UI 명령이 의도치 않은 로컬 파일/Unity 씬 변경을 일으킬 수 있음.
- 공개 loopback 포트/고정 토큰/로그 유출이 외부 프로세스의 오용으로 이어질 수 있음.
- 사용자 제공 에셋에 비정상 포맷, 경로 조작, 악의적 파일명이 포함될 수 있음.

## 원칙
1. **최소 권한:** 등록한 라이브러리 폴더와 승인한 Unity 프로젝트에서만 동작.
2. **명시적 분석:** 등록·검색·MCP 조회로 AI 호출 자동 실행 금지.
3. **원본 불변:** 원본 삭제/이동/수정 방지; Unity 대상 사본을 사용.
4. **외부 전송 고지:** 외부 API 선택·전송 데이터 유형·예상 비용·승인 기록.
5. **비밀 보호:** API 키는 Windows 자격 증명 또는 OS 보안 저장소, 설정/DB에 평문 저장 금지.
6. **로컬 채널 보호:** loopback bind, 실행 세션별 인증, 토큰 파일 Windows 사용자 ACL, 로그 토큰 레드랙션.
7. **MCP 권한 분리:** 검색/조회 읽기와 Unity 프로젝트 수정 쓰기를 구분; 계획 조회 후 승인.
8. **오류 가시성:** 거부/실패는 정확한 사유를 전달하고 성공으로 위장하지 않음.

## 검증 항목
- `..` 경로 순회, UNC/네트워크 공유, symlink 탈출, 드라이브 루트 접근을 허용 정책으로 검사.
- 공격적인 파일명/심볼릭 링크/비정상 파일 파싱 시 예외 처리 및 격리.
- 외부 모델 OFF 상태에서 실제 네트워크 송신 0건.
- 로그 파일 내 API 키·토큰·민감한 원본 내용 누출 검사.
- MCP 승인 없이 `Assets` 밖 파일 생성이나 기존 씬 덮어쓰기 불가.
- 사용자 데이터가 포함된 AppData는 설치 업데이트에서 유지, 제거 정책은 설치 옵션으로 명확히 안내.

## M02 구현 경계

- Vue에는 health/명시적 재연결만 노출한다. 실행 파일·인자·DB 경로·SQL·임의 Core 명령은 프런트엔드가 선택할 수 없다. release 자식은 설치 디렉터리의 고정 Sidecar만 실행하며 Python 환경/PATH 의존을 제거한다.
- 내부 파이프에는 UUID·PID·버전 검증과 16KiB/3초 제한을 둔다. 오류·응답 지연·비정상 종료는 세션을 수거하고 고정 오류만 표시한다. stderr·예외·환경·원본 경로는 기록/출력하지 않는다.
- DB는 환경 표식과 OS 단일 쓰기 잠금으로 보호한다. 호환되지 않거나 손상된 DB를 교체/초기화하지 않고 백업/원래 데이터를 유지한다. 연결 재시도는 사용자 명시 조작이며 분석/외부 모델/복구 작업을 자동 시작하지 않는다.
- 테스트/설치 검증은 프로젝트 내부 새 전용 데이터 경로를 사용한다. 원래 설치본·사용자 AppData·원본 에셋을 검증용 DB로 사용하지 않는다.

R03-01의 main 창 전용 `select_library_folder`는 인자를 받지 않고 실제 네이티브 선택 결과만 반환한다. 로컬 드라이브/하위 폴더 여부는 정규화 전후 검사하고 Windows 네트워크 드라이브도 거부한다. 일반 JS filesystem/dialog 권한을 열지 않으며 Core/DB/AI 권한을 확대하지 않는다. 선택 경로를 오류·로그에 출력하지 않는다.

R03-02 등록은 Tauri가 보관한 마지막 선택 경로와 다시 대조하고 Python에서도 실재/로컬/읽기 권한·중복/중첩을 검증한다. DB 쓰기는 Python의 값 바인딩 쿼리로만 수행한다. 새 UI 명령은 고정 등록/해제/목록 3개이며 임의 Core 메서드·SQL 실행을 허용하지 않는다. 해제는 등록 비활성화만 수행하며 원본/이력은 보존한다. 오류·통신 실패에 경로/키 원문을 반사하지 않고 불명확한 쓰기를 자동 재시도하지 않는다.

M03 스캔/메타데이터/미리보기는 활성 등록 루트와 실제 ID에만 접근한다. 재귀 진입 전 경로 범위·링크/리파스를 재검사하고 오류가 있는 스캔에서 미관찰 파일을 누락으로 확정하지 않는다. 미리보기는 PNG/JPEG와 입력/픽셀/출력 한도를 적용해 데이터 경로의 캐시에만 원자적으로 쓴다. 원본 파일·기존 태그/설명/분석 결과는 변경하지 않으며 AI 호출·임베딩·외부 전송은 하지 않는다. 파일 변경 판정은 크기/mtime 기반이며 대량 파일/경쟁적 파일시스템 변경에 대한 추가 강화는 안정화 범위다.

## M05 자격 증명
키는 Python ctypes를 통한 Windows CredWriteW/CredReadW/CredDeleteW(Generic, 현재 사용자 로컬 영속)에만 저장한다. DB 절대 경로 SHA256과 모델 UUID로 target을 구분해 개발/운영·테스트를 분리한다. 프런트엔드는 쓰기만 제공하며 키 조회는 허용하지 않는다. 저장·삭제 시 모델을 비활성화하고 인증 상태를 초기화한다. 별도 인증 검사는 외부 전송 동의 후 고정 OpenRouter /api/v1/key GET만 수행하며 응답의 키/사용량 상세를 UI에 반사하지 않는다. 모델 목록은 존재 여부만 반환하고 입력란은 처리 시작 시 비운다. vault 오류를 평문 파일/DB 저장으로 우회하지 않는다.

## M06 승인 실행 경계
분석의 진입점은 고정 analysis.start이며 confirmed:true·실제 모델/대상·미리보기 일치·작업별 외부/유료 승인·예약 한도를 검증한다. 조회/등록/스캔/미리보기로 Job이나 워커를 생성하지 않는다. 긴 호출은 작업 스레드에 격리하고 취소 시 소켓을 중단하며 HTTP 자동 재연결/자동 추론 재시도를 금지한다. 외부 호출 URL은 고정 OpenRouter HTTPS, 로컬은 고정 127.0.0.1 Ollama다. 환경 프록시·리다이렉트·임의 URL은 허용하지 않는다.

입력은 활성 등록 루트에 제한하고 원본 열린 핸들 경로·stat를 검증한다. 원본은 읽기만 하며 변환한 작은 JPEG만 전달한다. 파일/모델이 바뀌면 이전 검토를 암묵적으로 승계하지 않는다. 출력/오류는 제한된 설명/태그·사용량 및 고정 코드만 저장하고 자격 증명이 반사되면 거부한다. 키는 DB/스냅샷/로그/응답에 기록하지 않는다. 결과·완료 이력·Job 스냅샷은 DB 트리거로 보호한다.

Ollama CLI 및 qwen3-vl:2b 설치/다운로드와 실제 테스트 PNG 호출은 2026-10-28 사용자 명시 승인으로 개발 검증에서만 수행했다. 앱 실행·프로필 등록 시 설치/다운로드/분석을 자동으로 수행하지 않는다. 독립 로컬 런타임은 루프백 전용·클라우드 비활성 상태로 준비했다.
