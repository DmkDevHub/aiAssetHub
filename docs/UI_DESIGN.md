# UI_DESIGN — Blueberry 참고 3단 메인 화면

참고: [`../assets/ui_reference.jpg`](../assets/ui_reference.jpg). **디자인 레퍼런스**이며 제3자 로고·작품·텍스트·상표를 복제하지 않는다.

## 목표 레이아웃
```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ AI Asset Hub     경로/Breadcrumb           전역 검색        모델/설정      │
├────────────────┬─────────────────────────────────┬────────────────────────┤
│ 좌측 탐색기      │ 중앙 에셋 갤러리                 │ 우측 상세 패널         │
│ [+ 폴더 추가]   │ 검색·필터·정렬·뷰전환           │ 실제 미리보기          │
│ 전체/라이브러리  │ [AI 분석] [다중 선택 작업]       │ 파일 메타데이터        │
│ 폴더 트리       │ 실제 썸네일 카드 그리드         │ 태그·사용자 설명       │
│                │ 선택 상태/페이지 또는 스크롤     │ 분석 결과·이력        │
│                │                                 │ [Unity 적용]          │
├────────────────┴─────────────────────────────────┴────────────────────────┤
│ 작업 상태: 스캔/분석/Unity 작업, 진행률·실패 알림(작업 시에만)              │
└─────────────────────────────────────────────────────────────────────────────┘
```

- 메인 화면 자체가 **실제 에셋 관리/분석 작업 공간**. 통계용 대시보드 또는 개발 진행률 위젯 없음.
- 어두운 색상, 선명한 선택 강조색, 썸네일 카드와 오른쪽 상세 패널의 시각적 위계를 참고한다.
- 창 너비가 줄어들면 오른쪽 상세를 접을 수 있게 하고 왼쪽 트리를 리사이즈 가능하게 한다.
- 파일 종류에 따라 이미지 썸네일·3D 프리뷰(단계적)·오디오 아이콘/플레이어·지원하지 않는 파일 플레이스홀더.

## 주요 조작과 동작
| 사용자 조작 | 화면 동작 | 실제 처리 |
|---|---|---|
| `폴더 추가` | 폴더 선택기, 등록 폴더 트리 등장 | 경로 등록 + 파일 스캔; AI 미실행 |
| 폴더 클릭 | 해당 폴더의 에셋 카드 표시 | 실제 DB 조회 |
| 카드 1개 선택 | 우측 상세정보 변경 | 파일 정보·태그·분석 결과 조회 |
| Ctrl/Shift 다중 선택 | 카드 다중 강조 | 묶음 태그 적용, 선택 분석 |
| 검색/필터 | 조건에 맞는 카드 표시 | 파일명·태그·상태·형식·분석 텍스트 검색 |
| `AI 분석` | 범위/대상/모델/비용 확인 창 | **확정 클릭 후** 큐에 분석 작업 저장 |
| 분석 중 | 작업 상태 바, 성공·실패 건수 | 백엔드 실제 작업 상태 구독/폴링 |
| `Unity 적용` | 프로젝트/씬/배치 옵션 확인 | 연동 패키지에 실제 임포트·배치 요청 |

## AI 분석 다이얼로그 명세
1. 범위: `전체`, `미분석`, `분석 완료 재분석`, `실패 재시도`, `현재 선택 에셋`.
2. 대상: 현재 폴더(하위 폴더 포함 여부), 현재 라이브러리, 전체 라이브러리.
3. 모델: 로컬/외부 모델 선택; 능력 부족한 모델은 비활성화 및 이유 표시.
4. 실행 전: 실제 대상 개수·예상 API 비용(가능한 범위)·전송 범위·예산 잔액 표시.
5. 버튼: `취소` / `분석 시작` — 시작 클릭 전에는 작업이 생성되지 않는다.
6. 진행 화면: 처리 중인 에셋, 완료/실패 건수, 일시 중단 또는 취소, 로그/오류 상세.

## 상태·정확성
- 분석 아이콘은 `미분석/대기/진행/완료/실패/취소`를 실제 저장 상태에 따라 나타낸다. 이전 성공 결과 보유 여부는 별도 표시 가능.
- 로딩·빈 목록·권한 오류·오프라인·손상된 파일을 구별한다.
- 작업 미구현 플래그나 ROADMAP 상태를 UI에 노출하지 않는다.
- 예시 데이터가 아니라 실제 등록 파일과 엔진 응답만 표시한다. 테스트용 목업은 개발 모드에 한정.

## 접근성·사용성
- 키보드 탐색, 포커스 표시, 긴 파일명 축약 + 전체 경로 툴팁, 정렬·필터 상태 유지.
- 가상 스크롤 또는 페이지네이션으로 다량 에셋 처리; 썸네일 비동기 로딩.
- 원본 파일 삭제 등 위험한 작업은 기본 UI에 배치하지 않으며 원본 수정 시 별도 확인.

## 현재 상단 바 구현 범위 (R01-01)

- 공통 상단 바에 홈 링크, `작업 공간 / 현재 화면` 브레드크럼, 검색어 입력과 지우기, 화면 설정 링크를 제공한다. 현재 화면은 실제 라우터 메타데이터를 사용하며 등록하지 않은 폴더 경로를 만들지 않는다.
- 검색어는 Vue 공용 메모리 상태로 유지한다. 화면을 이동해도 보존되고 새로고침·앱 재실행 시 초기화된다. 지우기·조합 중이 아닌 Escape는 검색어를 비우고 검색 입력에 포커스를 돌린다.
- 한글 조합 중에는 확정된 검색어를 바꾸지 않는다. 조합 완료 시 반영하며 조합 중 Escape는 검색어를 지우지 않는다.
- 이 작업은 검색 입력 인터페이스다. 입력·Enter·화면 이동으로 검색 결과·분석 작업을 만들거나 AI/DB/Core를 호출하지 않는다. 실제 에셋 필터링은 M04에서 연결한다.
- D-019에 따라 실제 화면을 열지 않는 가상 DOM에서 렌더 출력·이벤트·라우팅·상태를 검증한다. 시각적 배치·OS 입력기 동작은 미검증이다.

## 현재 라이브러리 패널 구현 범위 (R01-02)

- 라이브러리 화면 왼쪽에 `전체 에셋` 선택 항목과 폴더 트리 패널을 배치한다. 등록·Core 연동 전인 현재 앱은 폴더 목록이 비어 있으며 `등록된 폴더가 없습니다.`를 표시한다. 임시 폴더·에셋 개수나 작동하지 않는 폴더 추가 버튼을 제공하지 않는다.
- 트리는 입력받은 `id`·`name`·선택적 `children`만 렌더링하고, 선택 시 해당 ID 또는 전체 선택을 뜻하는 `null`을 알린다. 실제 ID를 생성하거나 경로를 추측하지 않는다. 예시 트리는 내부 테스트 fixture로만 사용한다.
- 단일 선택과 키보드 포커스를 구분한다. 위/아래·Home/End는 보이는 항목 사이의 포커스를 옮기고, 좌/우는 부모 이동·접기/펼치기·첫 자식 이동, Enter/Space는 선택을 수행한다. 부모는 `aria-expanded`, 자식 목록은 `group`을 사용한다.
- 너비는 기본 240px, 200~360px 범위다. 구분선 드래그·좌우 방향키(16px)·Home/End로 조절하고 두 번 클릭하면 기본값으로 돌아간다. 너비·선택은 Vue 메모리 상태이며 재실행 시 초기화된다.
- 드래그 중 Escape는 시작 너비로 복원한다. 포인터 해제·취소·버튼 해제 감지·포커스 상실·컴포넌트 해제 시 이벤트를 정리한다. 화면 설정에 다녀와도 수락된 패널 너비를 유지한다.
- 이 작업은 UI 입력·선택 상태만 다룬다. 실폴더 등록·스캔·DB·AI 호출과 갤러리 필터링은 M03 이후 범위다. 실제 화면·보조기술·OS 포인터 동작은 미검증이다.

## 현재 중앙 갤러리 구현 범위 (R01-03)

- 중앙에 라이브러리 제목·입력된 에셋 개수·그리드/목록 전환을 제공한다. 현재 앱은 데이터 연결 전이므로 `0개 에셋`과 빈 라이브러리 안내를 표시한다. 검색어가 있어도 검색 결과를 조회했다고 표시하지 않는다.
- 그리드는 카드 목록, 목록은 에셋명·유형 열의 표다. 입력받은 ID·이름·유형만 표시하며 항목 순서와 개수를 보존한다. 긴 이름은 축약하고 전체 이름을 title로 제공하며 마크업 형태의 메타데이터도 텍스트로 처리한다.
- 카드의 유형 표시는 실제 썸네일이 아니다. 파일·이미지를 읽거나 미리보기를 생성하지 않으며 테스트 에셋은 내부 fixture에만 존재한다.
- 보기 방식은 기본 그리드이며 Vue 메모리 상태로 유지한다. 빈 상태에서도 전환 가능하고 화면 설정에 다녀와도 보존되며 새로고침·재실행 시 초기화된다.
- 실파일 조회·썸네일·정렬·다중 선택은 M03, 검색 필터 연동은 M04 범위다. 갤러리 조작으로 DB·Core·AI를 호출하지 않는다. 내부 DOM 테스트로 렌더·이벤트·상태를 확인했으며 실제 화면 배치·OS 동작은 미검증이다.

## 현재 상세 패널 구현 범위 (R01-04)

- 기본 앱은 에셋 선택 전 안내를 표시한다. 그리드/목록의 이름 버튼으로 입력받은 에셋 하나를 선택하면 오른쪽 기본 정보에 이름·유형을 표시한다. 목록에서 제거된 선택은 즉시 비운다.
- 기본 정보/분석 결과 탭은 좌우·Home/End 키와 클릭으로 이동한다. 분석 탭은 제공된 `analysisText`만 텍스트로 표시하며 없으면 제공된 결과가 없다고 알린다. 실제 분석 여부·성공·모델을 추측하거나 조회하지 않는다.
- 접기 버튼은 항상 접근 가능하며 숨긴 패널의 선택/탭을 보존한다. 접기 설정은 화면 이동 동안 메모리에 유지한다. 선택한 에셋이 달라지면 기본 탭으로 돌아간다.
- 실제 파일 속성/미리보기는 M03, 분석 결과 조회는 M06에 연결한다. fixture는 내부 자동화에만 사용하며 앱에 예시 데이터를 공급하지 않는다.
